## 🚀 How to Run (Quick Start)

### 1️⃣ **Install Dependencies**
```bash
npm install
```

### 2️⃣ **Start Backend Server**
```bash
npm start
```
(Runs on http://localhost:5000)

### 3️⃣ **Start Frontend Server** (New Terminal)
```bash
python -m http.server 8000
```

### 4️⃣ **Open Browser**
```
http://localhost:8000
```

**That's it! App is running!** 🎉
